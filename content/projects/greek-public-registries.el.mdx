Όλα εδώ τρέχουν πάνω σε **ανοικτά δεδομένα του ελληνικού δημοσίου**: τη Διαύγεια,
όπου οι αποφάσεις του δημόσιου τομέα δημοσιεύονται εκ του νόμου, και το ΚΗΜΔΗΣ,
το κεντρικό ηλεκτρονικό μητρώο δημοσίων συμβάσεων. Κανένα διαπιστευτήριο, κανένα
ιδιωτικό endpoint, τίποτα που δεν είναι ήδη δημόσιο.

## Το φύλλο μένει

Τα scripts δεν εισάγουν βάση δεδομένων, ούτε διεπαφή, ούτε νέο μέρος όπου
φυλάσσεται η δουλειά. Διαβάζουν το ίδιο `.xlsx` που ήδη συμπληρωνόταν στο χέρι,
και γράφουν στην ίδια στήλη.

Αυτός ο περιορισμός είναι ο λόγος που το εργαλείο χρησιμοποιήθηκε πράγματι. Ένα
εργαλείο που ζητά από κάποιον να μεταφέρει τη διαδικασία του είναι εργαλείο που
αξιολογείται· ένα εργαλείο που συμπληρώνει τη στήλη που θα συμπλήρωνε ούτως ή
άλλως απλώς τρέχει.

Αυτό όμως σημαίνει να αντιμετωπίσεις πώς είναι τα πραγματικά φύλλα. Η γραμμή
επικεφαλίδων δεν είναι η πρώτη — υπάρχει τίτλος, μια κενή γραμμή, ένα
συγχωνευμένο κελί που πρόσθεσε κάποιος. Οπότε το script ψάχνει τη γραμμή που
περιέχει τις επικεφαλίδες που χρειάζεται και παίρνει από εκεί τις θέσεις των
στηλών. Το επόμενο αρχείο, με δύο γραμμές παραπάνω στην κορυφή, εξακολουθεί να
δουλεύει.

## Και προς τις δύο κατευθύνσεις, με σελιδοποίηση

Η αναζήτηση πηγαίνει και από τις δύο μεριές: από αριθμό πρωτοκόλλου στον
δημοσιευμένο ΑΔΑ, και από ΑΔΑ πίσω στον αριθμό πρωτοκόλλου της ανάληψης
υποχρέωσης στην οποία παραπέμπει — με φιλτράρισμα στον τύπο της απόφασης αντί να
λαμβάνεται το πρώτο αποτέλεσμα, γιατί μια αναζήτηση μπορεί θεμιτά να επιστρέψει
περισσότερα από ένα.

Ένα τρίτο script απαντά σε εντελώς άλλο ερώτημα: πόσες αποφάσεις δημοσίευσε ένας
φορέας σε ένα διάστημα. Αυτό διατρέχει το API ανά 500 εγγραφές μέχρι να γυρίσει
άδειο, που είναι ο μόνος ειλικρινής τρόπος να μετρήσεις κάτι του οποίου δεν ξέρεις
το μέγεθος εκ των προτέρων.

## Το ΚΗΜΔΗΣ είναι αρχή, όχι κεφάλαιο

Το σκέλος των προμηθειών είναι δώδεκα γραμμές πάνω στο endpoint των φορέων: αρκετές
για να επιβεβαιωθεί ότι το API απαντά, τι επιστρέφει, και ότι η ελληνική κεφαλίδα
γλώσσας μετράει. Είναι διερευνητικό, και το να ονομαστεί κάτι παραπάνω θα ήταν να
ντυθεί μια δοκιμή ως χαρακτηριστικό.

Ο επίσημος δειγματικός client της Διαύγειας βρίσκεται στον φάκελο για αναφορά· τα
scripts που περιγράφονται παραπάνω είναι γραμμένα απευθείας πάνω στο HTTP API.
