## Φάση 3 — Design system ✅
- [x] Editorial κατεύθυνση (D14): serif επικεφαλίδες, grid, γενναιόδωρο κενό
- [x] Τυπογραφία **με ελληνική κάλυψη**: Source Serif 4 + Inter, self-hosted
- [x] Χρωματικά tokens σε τρεις καταστάσεις: system / light / dark
- [x] Διακόπτης θέματος τριών θέσεων, με μνήμη και χωρίς λευκή αναλαμπή (D16)
- [x] Header με menu, footer, skip-to-content link
- [x] Σκελετικές σελίδες `/about`, `/cv`, `/contact` — κανένας σπασμένος σύνδεσμος
- [x] Επέκταση schema για τις απαιτήσεις D15
- [x] `StackDiagram` — το stack ως στρώματα αρχιτεκτονικής, όχι σειρά από badges
- [x] `Gallery` — φωτογραφικό υλικό με λεζάντες που χρησιμεύουν και ως `alt`
- [x] Ανασχεδιασμός αρχικής, `/projects` και σελίδας project
- [x] `metadataBase` ώστε οι OG εικόνες να δουλεύουν σε social shares

**Επαληθεύτηκε**
- 17 στατικές σελίδες. `typecheck` / `lint` / `npm audit` καθαρά.
- Γραμματοσειρές **όντως φορτώνονται** (`Source Serif 4`, `Inter` — όχι fallback).
- Τα ελληνικά κεφαλαία χάνουν σωστά τον τόνο (`ΑΥΤΟΜΑΤΙΣΜΟΙ`) — δουλεύει μόνο
  επειδή το `lang="el"` είναι σωστό.
- Διακόπτης θέματος: πλήρης κύκλος `system → light → dark → system`, με το
  background να αλλάζει και το εικονίδιο να ακολουθεί (`◐ ☀ ☾`).
- Σελίδα project: 4 πεδία αφήγησης, 4 στρώματα stack, 2 εικόνες, 2 σύνδεσμοι.
- Καμία οριζόντια υπερχείλιση στα 375px. Μηδέν console errors σε καθαρή φόρτωση.

**Δύο σφάλματα που βρέθηκαν και διορθώθηκαν**
1. Ο διακόπτης θέματος **κολλούσε** μετά το πρώτο κλικ: ο handler διάβαζε την τιμή
   από το closure του render, οπότε δύο κλικ στο ίδιο tick έβλεπαν την ίδια παλιά
   τιμή. Λύθηκε διαβάζοντας την τρέχουσα τιμή τη στιγμή του κλικ.
2. `z.record` με enum κλειδιά απαιτεί **όλα** τα κλειδιά — έσπαγε κάθε project που
   δεν είχε και τα τέσσερα στρώματα. Αντικαταστάθηκε με ρητά optional πεδία.

**Εκκρεμότητα:** οι εικόνες είναι placeholders. Το editorial ύφος στηρίζεται στις
εικόνες — μόλις δώσεις screenshots, το site αλλάζει επίπεδο.
